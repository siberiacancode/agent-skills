# User Sequence Diagrams

Create PlantUML sequence diagrams for meaningful user-initiated scenarios in `documentations/scenarios/<area>/<scenario>.puml`. Show the user's action, essential participants, important decisions, and the outcome visible to the user. Keep the diagram short enough to understand at a glance; split distinct user journeys into separate diagrams.

Use the vocabulary and interactions supported by the specification and code. Include internal services only when their interaction explains the user's result. Describe build, deployment, and background synchronization in architecture documentation instead. Check PlantUML syntax and readable labels.
