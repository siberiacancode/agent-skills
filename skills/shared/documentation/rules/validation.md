# Form Validation

Maintain one validation table per user-facing form at `documentations/validations/<form-name>.md`. Describe input fields, conditions, accepted values, requiredness, validation triggers, and user-visible errors based on agreed requirements and existing schema or form behavior.

Use a compact Markdown table with columns `Поле | Правило | Ошибка` and add a short note only when cross-field rules or submission behavior need clarification. Keep validation documentation aligned with code and linked test cases.
