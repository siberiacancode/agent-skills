# PlantUML conventions

Use PlantUML sequence diagrams for meaningful user journeys grounded in the approved specification and verified code.

> **Read [plantuml-file-structure](./plantuml-file-structure.md) for file ownership and [plantuml-sequence](./plantuml-sequence.md) for diagram content.**

Use existing project diagram conventions where applicable. Keep participants, actions, decisions, and outcomes consistent with the source material. Validate PlantUML syntax before saving.
