# Language

- Use English for planning, agent-to-agent instructions, tool requests, and intermediate technical notes when supported by the environment.
- Communicate with the user in Russian: questions, recommendations, progress, and final responses.
- Write generated prose artifacts in Russian, including feature specifications.
- Preserve existing identifiers, code, commands, paths, API names, and established technical terms in their original language.
